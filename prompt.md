Projeto BrBox (jun de 2020 - dez de 2021)

BrBox é uma plataforma mobile de catálogo e recomendação de jogos utilizando Inteligência Artificial, desenvolvida com arquitetura full stack e microsserviços. Atuei no desenvolvimento do aplicativo mobile em React Native, da API REST em Node.js/TypeScript e na integração do sistema de recomendações baseado em Machine Learning em Python. O projeto inclui autenticação JWT, gerenciamento de usuários, sistema de avaliações com tags, integração com banco PostgreSQL, carregamento automático de jogos da Steam e recomendações personalizadas utilizando filtragem colaborativa (SVD).

Projeto Tinsports

Tinsports é uma plataforma mobile para gerenciamento de eventos esportivos, focada principalmente em partidas de futebol. Atuei no desenvolvimento full stack da aplicação, incluindo o app mobile em React Native, API REST em Node.js/TypeScript e integração com MongoDB. O sistema permite criação de eventos, gerenciamento de convites, confirmação de presença, avaliação de jogadores, sistema de reputação e assinatura premium com integração de pagamentos via Google Pay. Também participei da estruturação da arquitetura da aplicação, autenticação JWT, upload de imagens com Firebase e implementação de funcionalidades premium (TinsBoss).
